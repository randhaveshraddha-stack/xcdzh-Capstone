# Full-Stack Development Capstone Project - Cars Dealership

## Project Overview
This repository contains the complete full-stack application for Cars Dealership, a national car retailer in the U.S. The application features a multi-microservice architecture including:
- **Django Backend & Authentication** (User management, database proxy, and admin dashboard)
- **Node.js & MongoDB Microservice** (Dealership locations and reviews)
- **Flask & Sentiment Analysis Microservice** (Review sentiment scoring)
- **React Frontend** (Responsive UI for viewing dealers and submitting reviews)
- **Deployment** (Containerized with Docker and deployed via IBM Cloud Code Engine)
